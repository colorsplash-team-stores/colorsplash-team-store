# ColorSplash Team Store

Online team stores for ColorSplash Uniforms & Embroidery (Pueblo, CO).

- `index.html` — the whole site: team store pages (`/s/<team>`) and the store admin (`/admin`).
- `vercel.json` — routes for Vercel.
- `supabase-setup.sql` — database setup for the Supabase project `colorsplash-team-store`.
- `teams/` and `brand/` — logos.

Each push to `main` deploys to Vercel.
